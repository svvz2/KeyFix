# KeyFix

برنامج Windows خفيف لتصحيح النص المكتوب بتخطيط لوحة مفاتيح خاطئ بين **English US** و **Arabic 101**.

```text
hgsghl ugd;l  →  السلام عليكم
lvpfh          →  مرحبا
السلام         →  hgsghl
```

معالجة النص محلية بالكامل. لا يحتاج البرنامج إلى حساب، ولا يحفظ النص الذي يكتبه المستخدم. الاتصال بالإنترنت اختياري ويُستخدم فقط لجلب روابط التواصل والإعلانات وفحص التحديثات من مستودع GitHub الرسمي.

يعرض الإصدار **1.4.0** حسابات المشروع في الصفحة الرئيسية، ويربط أخبار البرنامج والتحديثات وروابط التحميل بملف قناة عام على GitHub، مع بقاء التصحيح والاقتراحات الذكية محلية بالكامل.

## التشغيل

النسخة الجاهزة توجد بعد البناء داخل:

```text
artifacts/KeyFix-win-x64/KeyFix.App.exe
```

شغّل الملف وسيظهر KeyFix مع أيقونة دائمة في منطقة النظام. إغلاق النافذة لا يغلق البرنامج؛ استخدم **خروج** من قائمة أيقونة النظام لإنهائه.

## الاختصارات

| الوظيفة | الاختصار |
|---|---|
| تصحيح النص المحدد | `Ctrl + Alt + K` |
| تصحيح آخر كلمة | `Ctrl + Alt + Space` |
| التراجع عن آخر تصحيح | `Ctrl + Alt + Z` |
| إيقاف أو تشغيل مؤقت | `Ctrl + Alt + P` |

### مثال سريع

1. افتح Notepad أو Word أو المتصفح.
2. اكتب `hgsghl ugd;l`.
3. حدد النص.
4. اضغط `Ctrl + Alt + K`.
5. يتحول النص إلى `السلام عليكم`.

يمكن أيضاً تحديد النص ثم الضغط بالزر الأيمن؛ يظهر إجراء **تصحيح اللغة** قرب قائمة السياق. هذا الإجراء يكتشف الاتجاه تلقائياً، سواء كان النص إنكليزياً مطلوباً بالعربي أو عربياً مطلوباً بالإنكليزي.

عند تفعيل **الاقتراحات الذكية** من الإعدادات، يراقب KeyFix الكلمة الحالية داخل الذاكرة فقط. بعد كتابة كلمة مثل `hgsghl` والضغط على المسافة يظهر اقتراح هادئ لتحويلها إلى `السلام`. يختفي الاقتراح تلقائياً، أو عند متابعة الكتابة، ويمكن تجاهله من دون تغيير النص.

## الخصائص

- تصحيح النص المحدد من أي برنامج يدعم النسخ وإدخال Unicode.
- تصحيح آخر كلمة بدون تحديد يدوي.
- إجراء تصحيح سريع يظهر قرب قائمة الزر الأيمن.
- مراقبة ذكية اختيارية للكلمة الحالية مع تنبيه هادئ وخياري **تصحيح** و**تجاهل**.
- اكتشاف اتجاه التحويل تلقائياً أو تثبيته من الإعدادات.
- تبديل لغة الإدخال بعد التصحيح، بشكل اختياري.
- Undo لآخر عملية حديثة داخل النافذة نفسها.
- تشغيل من System Tray وتشغيل اختياري مع Windows.
- قائمة تطبيقات مستثناة.
- حماية حقول كلمات المرور التي يعرّفها Windows كحقول محمية.
- حفظ الإعدادات محلياً في `%LOCALAPPDATA%\KeyFix`.
- سجل تقني محدود الحجم لا يحتوي النصوص المكتوبة.
- الاقتراحات الذكية تعمل محلياً، لا تحفظ الكلمات، وتتوقف في حقول كلمات المرور والتطبيقات المستثناة.
- فحص تحديثات اختياري من GitHub مع تنبيه هادئ ورابط تحميل يحدده مالك المستودع.
- قناة إعلانات وتواصل مركزية يمكن تحديثها من [`channel.json`](channel.json) من دون إصدار نسخة جديدة من البرنامج.

## حدود النسخة الحالية

- التطبيق الذي يعمل كمسؤول قد لا يقبل إدخالاً من KeyFix عندما يعمل KeyFix بصلاحية عادية.
- بعض المحررات المخصصة أو الألعاب لا تدعم آلية النسخ أو Unicode input القياسية.
- التحويل المعلن والمدعوم حالياً هو English US مع Arabic 101.
- لا يوجد تصحيح تلقائي للكلمات؛ النسخة الحالية يدوية لتجنب التصحيحات الخاطئة.

## التطوير

المتطلبات:

- Windows 10/11 x64.
- .NET 10 SDK.

الأوامر:

```powershell
dotnet restore KeyFix.slnx
dotnet build KeyFix.slnx
dotnet test KeyFix.slnx
dotnet publish src\KeyFix.App\KeyFix.App.csproj -p:PublishProfile=WinX64
```

أو شغّل:

```powershell
.\build-release.ps1
```

لإنشاء حزمة المستخدمين وحزمة المصدر وبصمات SHA-256:

```powershell
.\build-packages.ps1
```

راجع [دليل النشر](docs/PUBLISHING.md) و[سياسة الخصوصية](docs/PRIVACY.md) قبل الإصدار العام.
طريقة إدارة روابط التواصل والتحديثات موضحة في [دليل قناة GitHub](docs/GITHUB-CHANNEL.md).
