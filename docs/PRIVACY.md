# خصوصية KeyFix

KeyFix مصمم لمعالجة النص محلياً على جهاز Windows من دون حساب أو خدمة سحابية.

## البيانات التي يعالجها

- عند استخدام الاختصار اليدوي، يقرأ البرنامج النص المحدد مؤقتاً عبر الحافظة ثم يعيد محتوى الحافظة السابق.
- عند تشغيل الاقتراحات الذكية، يحتفظ بالكلمة الحالية في الذاكرة فقط وبحد أقصى 24 محرفاً.
- تُمسح الذاكرة المؤقتة عند تغيير النافذة، استخدام أوامر لوحة المفاتيح، تعطيل الميزة، أو إغلاق البرنامج.

## البيانات التي لا يجمعها

- لا يرسل النصوص إلى الإنترنت.
- لا يخزن الكلمات أو محتوى الحافظة في الملفات أو السجل التقني.
- لا يعالج حقول كلمات المرور التي يعرّفها Windows كحقول محمية.
- لا يعالج التطبيقات الموجودة في قائمة الاستثناءات.
- يتجاهل إدخالات لوحة المفاتيح المحقونة برمجياً في نسخة الإصدار.

## الاتصال بـ GitHub

عند بدء البرنامج أو اختيار **فحص التحديثات**، يطلب KeyFix ملف `channel.json` العام من مستودع المشروع. يحتوي الملف فقط على رقم آخر إصدار، رابط التحميل، إعلان المشروع، وروابط التواصل.

- لا يُرسل أي نص مكتوب أو محتوى حافظة أو إعداد شخصي إلى GitHub.
- لا يتطلب الطلب حساب GitHub أو رمز دخول.
- عند غياب الإنترنت، يستمر التصحيح بصورة طبيعية وتبقى روابط التواصل الافتراضية متاحة.
- مثل أي طلب ويب عادي، قد ترى GitHub عنوان IP ومعلومات تقنية محدودة عن الطلب مثل اسم البرنامج وإصداره.

بعض التطبيقات المخصصة لا تعرّف حقولها الحساسة إلى Windows بصورة قياسية؛ لذلك تبقى إضافة التطبيقات الحساسة إلى قائمة الاستثناءات إجراءً موصى به.
