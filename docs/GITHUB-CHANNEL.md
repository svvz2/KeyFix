# قناة KeyFix على GitHub

يقرأ البرنامج الملف العام [`channel.json`](../channel.json) عند التشغيل وعند اختيار **فحص التحديثات** من قائمة أيقونة النظام. هذا الملف هو حلقة الوصل الوحيدة للأخبار وروابط التواصل والتحديثات، ولا يحتوي أسراراً أو رموز دخول.

## تغيير حسابات التواصل

عدّل القيم داخل `social`:

```json
"social": {
  "instagramHandle": "@22r2z",
  "instagramUrl": "https://www.instagram.com/22r2z/",
  "telegramHandle": "@Civil_Sajad",
  "telegramUrl": "https://t.me/Civil_Sajad"
}
```

ستظهر القيم الجديدة للمستخدمين عند الفحص التالي من دون الحاجة إلى تحديث البرنامج.

## إرسال إعلان للمستخدمين

ضع `enabled` على `true` وعدّل النص والرابط داخل `announcement`. لإخفاء الإعلان غيّرها إلى `false`. اجعل الرسالة قصيرة لأن الإعلان يظهر داخل الصفحة الرئيسية.

## نشر تحديث

1. حدّث رقم النسخة في `KeyFix.App.csproj` والواجهة وسجل التغييرات.
2. شغّل `build-packages.ps1` وتأكد من نجاح الاختبارات.
3. عدّل `update.latestVersion` إلى الرقم الجديد.
4. ضع رابط ZIP الرسمي في `update.downloadUrl` ورابط صفحة الإصدار في `releaseNotesUrl`.
5. ارفع التغييرات وأنشئ Tag مطابقاً، مثل `v1.4.0`.

يقارن البرنامج `latestVersion` بإصداره الحالي. إذا كان الرقم أحدث يظهر بانر يحتوي رسالة التحديث وزري التفاصيل والتحميل. كل الروابط التي يقبلها البرنامج يجب أن تبدأ بـ `https://`.

## الأمان

- لا تضع GitHub token أو كلمة مرور داخل `channel.json` أو أي ملف في المستودع.
- رمز GitHub يستخدم فقط من جهاز المالك أو من Secrets الخاصة بـ GitHub Actions.
- لا تغيّر `schemaVersion` إلا عند تحديث البرنامج لدعم بنية جديدة.
